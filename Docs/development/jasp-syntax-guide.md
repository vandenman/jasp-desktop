# Guide for building, installing and using jaspSyntax
## <span style="color:red">Be careful, the jaspSyntax is still in development!</span>

jaspSyntax is the R package that allows users to run the JASP analyses directly in R (Studio). It can load data from a R DataFrame,
and run (most of) the JASP analyses. You can in fact just copy the R Syntax generated by JASP (click the 'R' icon in your analysis),
and paste this code in your R (Studio) environment, and get the same results as if you were using JASP.

```R
jaspTTests::TTestIndependentSamples(
          data = <name of the R Data Frame>,
          version = "0.95",
          formula =  ~ contNormal + contGamma,
          descriptivesPlot = TRUE,
          group = ~ contBinom)
```

In this code jaspTTests::TTestIndependentSamples will call first a wrapper that explicitly sets all default values and checks the formula syntax.
Then it calls jaspSyntax:
- to load the R Data Frame,
- to load the QML form that defines the analysis options and check all constraints
- to run the analysis in R as if it was called from JASP
- to return the result as an R object.

You can then manipulate the tables and plot objects in R.

jaspSyntax has also special functions to generate the analysis R wrappers.

## Quick install (macOS / Windows — pre-built binary)

If a pre-built SyntaxInterface library is available for your platform, you can install jaspSyntax directly:

```bash
# From R:
remotes::install_github("jasp-stats/jaspSyntax")
```

This will automatically download the JASP SyntaxInterface library from our server.

## Building from source (all platforms)

If you need to compile the SyntaxInterface library yourself (required on Linux, optional on macOS/Windows), follow these steps.

### Prerequisites

| Dependency | Notes |
|---|---|
| **CMake** ≥ 3.21 | Build system |
| **Ninja** | Recommended generator (Ninja builds are much faster) |
| **Qt 6 sources** | Installed via Qt Maintenance Tool; need at least: `qtbase`, `qtdeclarative`, `qtshadertools`, `qt5compat`, `qtpositioning` |
| **R** | With development headers (`R.h`), Rcpp and RInside will be installed automatically |
| **C++ compiler** | Supporting C++20 (GCC ≥ 11, Clang ≥ 14, MSVC ≥ 2022) |
| **System libraries** | `zlib`, `openssl`, `libarchive`, `sqlite3`, `jsoncpp`, `boost`, `readstat`, `freexl`, `librdata` |
| **gfortran, flex, bison** | Required on Linux |
| **GITHUB_PAT** | A GitHub Personal Access Token, set as an environment variable |

### Step 1: Build Qt statically

Install the Qt sources via the Qt Maintenance Tool (or download them). Then build a static Qt with only the modules jaspSyntax needs:

```bash
# Navigate to the Qt source directory (e.g. ~/Qt/6.10.1/Src)
cd ~/Qt/6.10.1/Src

# Configure a static release build
# On Windows: remove rtools from your PATH first, and run vcvarsall.bat to set MSVC paths.
./configure -release -static -opensource -confirm-license \
  -prefix ../BuildStaticRelease \
  -submodules qtbase,qtdeclarative,qtshadertools

# Build and install
cmake --build . --parallel
cmake --install .
```

After this completes, your static Qt will be in e.g. `~/Qt/6.10.1/BuildStaticRelease/`.

### Step 2: Build the SyntaxInterface library

Clone jasp-desktop if you haven't already:

```bash
git clone https://github.com/jasp-stats/jasp-desktop.git
cd jasp-desktop
```

Configure and build using CMake from the command line (no Qt Creator needed):

```bash
# Make sure GITHUB_PAT is exported
export GITHUB_PAT="your_github_pat_here"

# Create a build directory
mkdir -p build/SyntaxRelease
cd build/SyntaxRelease

# Configure with static Qt
# Adjust paths to match your system:
#   CMAKE_PREFIX_PATH → your static Qt install
#   CUSTOM_R_PATH     → your R installation (Linux only; omit on macOS/Windows)
cmake -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_PREFIX_PATH=~/Qt/6.10.1/BuildStaticRelease \
  -DCUSTOM_R_PATH=/path/to/your/R \
  -DINSTALL_R_MODULES=OFF \
  -DBUILD_TESTS=OFF \
  ../../

# Build only the SyntaxInterface target (not all of JASP)
ninja SyntaxInterface
```

This produces `libSyntaxInterface.so` (Linux), `libSyntaxInterface.dylib` (macOS), or `SyntaxInterface.dll` (Windows) in `build/SyntaxRelease/SyntaxInterface/`.

### Step 3: Build jaspSyntax

Clone jaspSyntax:

```bash
git clone https://github.com/jasp-stats/jaspSyntax.git
cd jaspSyntax
```

Since jaspSyntax uses renv, first restore its dependencies, then install the package pointing to your build:

```bash
# Restore renv dependencies (installs Rcpp)
R --slave --no-restore --no-save -e 'renv::restore()'

# Set the build & source directories and install from source
# JASP_BUILD_DIR = the CMake build directory (contains SyntaxInterface/)
# JASP_SOURCE_DIR = the jasp-desktop source tree (contains SyntaxInterface/syntaxbridge_interface.h)
JASP_BUILD_DIR="/path/to/jasp-desktop/build/SyntaxRelease" \
JASP_SOURCE_DIR="/path/to/jasp-desktop" \
R --slave --no-restore --no-save -e '
  options(configure.vars = c(jaspSyntax = paste0(
    "JASP_BUILD_DIR=", Sys.getenv("JASP_BUILD_DIR"),
    " JASP_SOURCE_DIR=", Sys.getenv("JASP_SOURCE_DIR")
  )))
  install.packages(".", repos = NULL, type = "source")
'
```

Verify it works:

```bash
R --slave -e 'library(jaspSyntax); cat("jaspSyntax loaded OK\n")'
```

## Run jaspSyntax
- Install first a JASP module, for example jaspTTests `remotes::install_github("jasp-stats/jaspTTests")`
- Load a data file: `myData <- read.csv("<path to a csv file>")`
- You can load the data file each time you run an analyse, but you can also load it once via: `jaspSyntax::loadDataSet(myData)`
- Then you can run an analysis with:
```R
jaspTTests::TTestIndependentSamples(
          version = "0.95",
          formula =  ~ contNormal + contGamma,
          descriptivesPlot = TRUE,
          group = ~ contBinom)
```
